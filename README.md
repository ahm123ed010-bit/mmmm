# المؤرخ — نسخة C# (ASP.NET Core 8 + PostgreSQL)

منصة مستر شريف للدراسات الاجتماعية، مكتوبة بالكامل بـ C#. نفس فكرة مشروع Next.js القديم ومعاه الأجزاء اللي كانت "جاية" في الدليل.

## اللي في المشروع
- تسجيل دخول وصلاحيات: أدمن (مستر شريف) / مدرس (مجموعاته بس) / طالب. تعطيل الحساب أو الفصل بيطلّع الطالب فورًا.
- الحضور بالـ QR مربوط بموقع القاعة (GPS) من غير مؤقّت، وبيفضل شغّال لحد إنهاء الحضور.
- صفحة `/attend` للطالب (PWA): كاميرا + GPS + تسجيل بدون نت بيتبعت بعدين.
- ربط الطالب بموبايل واحد (توقيع ECDSA P-256) وفك الربط من صفحة الطلاب.
- الانضباط: إنذار وفصل بعد غيابات الشهر، أعذار، تأكيد الفصل أو فصل تلقائي، وإرجاع الطالب.
- **الواجبات** (نشر + تسليم + تصحيح + إشعارات)، **الفيديوهات** (رفع بشريط تقدّم + مشاهدة + متابعة)، **الإعلانات**، **الجدول**، **الدرجات والاختبارات**، **صفحات الطالب الكاملة**.
- عربي / English (زرار في القايمة)، وتغيير كلمة المرور من جوه الموقع.

## التشغيل على جهازك (ويندوز + VS Code)
1. ثبّت **.NET 8 SDK** من dot.net
2. اعمل قاعدة PostgreSQL مجانية على neon.tech وانسخ الرابط (Connection string).
3. في فولدر المشروع انسخ `.env.example` باسم جديد `.env` (في VS Code: كليك يمين على الملف → Copy، بعدين Paste، وغيّر الاسم إلى `.env`).
4. افتح `.env` وعدّل سطرين:
   ```
   DATABASE_URL="رابط-نيون-بتاعك"
   ADMIN_PASSWORD="باسورد-قوي-8-حروف-أو-أكتر"
   ```
5. من الترمنال في فولدر المشروع (اللي فيه `Moarekh.csproj`):
   ```
   dotnet run
   ```
6. افتح الرابط اللي يظهر (`http://localhost:5000` تقريبًا) وادخل بـ `sherif` (أو `ahmed`) وباسورد `ADMIN_PASSWORD`.

ملف `.env` مش بيترفع على GitHub (موجود في `.gitignore`). الجداول وحسابات الأدمن بيتعملوا لوحدهم أول تشغيل. بديل عن `.env`: تحط المتغيّرات في PowerShell بـ `$env:DATABASE_URL="..."` و`$env:ADMIN_PASSWORD="..."` قبل `dotnet run` (في نفس نافذة الترمنال).

## مهم: قارئ الـ QR على الآيفون
حمّل ملف `jsQR.js` من `https://cdn.jsdelivr.net/npm/jsqr@1.4.0/dist/jsQR.js` وحطّه في `wwwroot/lib/jsQR.js`. (أندرويد/كروم بيستخدموا قارئ المتصفح الجاهز، لكن سفاري محتاج الملف ده. لو ما حطّيتوش بيتحمّل من النت أول مرة ويتخزّن.)

## النشر
- الكاميرا والـ GPS والتشفير شغّالين على **HTTPS** بس.
- فيه `Dockerfile`. انشره على Render أو Railway أو Azure أو أي VPS، وحط `DATABASE_URL` و`ADMIN_PASSWORD`.
- **لازم قرص دائم (Volume)** متوصّل على `/data` عشان الواجبات والفيديوهات (`STORAGE_PATH=/data/storage`)، وإلا هتضيع مع كل نشر. فيديوهات كتير ← الأفضل بعدين تنقلها لـ Cloudflare R2/S3 (بتبدّل كلاس `FileStore` بس).

## تنبيهات صريحة
- **الكود ما اتجمّعش ولا اتجرّب** هنا (مفيش .NET ولا نت عندي). ممكن تظهر أخطاء بناء بسيطة أول `dotnet run`: ابعتلي نصها وأصلحها.
- ده مشروع جديد بقاعدة بيانات جديدة: داتا النسخة القديمة (Prisma) ومعاها كلمات المرور (Argon2) **ما اتنقلتش**. ابدأ بقاعدة فاضية.
- الجداول بتتعمل بـ `EnsureCreated`. لو غيّرت الموديلات بعدين استخدم EF Migrations.
- تحسين على القديم: التوقيت بتوقيت القاهرة في كل حاجة، وصفحة المدرس القديمة كانت بتعمل لفّة تحويل لا نهائية وأتصلحت (المدرس بيشوف مجموعاته بس).
- مفيش "المراجع/Resources" ولا مرفقات الإعلانات (مكانتش في العرض التجريبي).
